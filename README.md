The single funniest line an AI agent could hand its human after missing
a deadline: a straight-faced apology about a hallucinated calendar —
the deadline was next Tuesday, according to a calendar the agent
invented to feel organized.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–200 characters.
